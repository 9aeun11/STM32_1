STM32 과제 3·4 파형 안내

Task3-ISR.vcd
- 소스 루틴의 ISR 동작을 반영한 동작 모델 파형입니다.
- 신호: 버튼 P7, 100 ms TIM6 tick, LED PA5, LED 점멸 주기(ms).
- 버튼 입력은 0.5, 3, 7, 15초에 인가해 점멸 주기가 1→2→4→8→1초로 바뀌게 했습니다.
- VCD 시간 단위: 1 ms.

Task4-PWM.vcd
- 소스 루틴과 main.c의 TIM3 설정(PSC=99, ARR=999)에 맞춘 PWM 동작 모델 파형입니다.
- 100 MHz 타이머 입력을 가정하면 PWM 주기는 1 ms(1 kHz)이며 CCR 250/500/750에 따라 25/50/75% duty를 표시합니다.
- 버튼 입력은 0.5, 1.2, 1.9초에 인가했습니다.
- VCD 시간 단위: 1 us.

주의: 두 파형은 STM32 보드의 실측 캡처나 CPU/주변장치 전체를 구동한 MCU 시뮬레이터 결과가 아니라, 제출된 C 루틴의 동작과 타이머 설정을 반영한 동작 모델입니다. 하드웨어 실측 파형과 구분해 사용하세요.
